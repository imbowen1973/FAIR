eduFAIR Documents

Bring a lesson plan or workbook out of git and into Word

Libraries are shared with the PowerPoint pane: add one in either and it is there in the other. Public repositories are read straight from git and rendered here — nothing is uploaded.

No template is used. The document names Word's built-in styles, so it takes its fonts and colours from your own Word theme — change the theme and the document follows.
