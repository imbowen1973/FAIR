FAIR Deck Assembler

Teaching content lives as markdown in git. This builds it into PowerPoint, in your browser.

This page hosts the add-in itself — the tool, never content. No deck is stored here and no catalog is published. A library is a plain git repo of markdown; the pane fetches it straight from git and runs the renderer in your browser tab, so the .pptx exists only while you are using it.

Install it in PowerPoint

Download manifest.web.xml, then in PowerPoint on the web: Add-ins → Upload My Add-in. On desktop, sideload the same file. It points here, so there is nothing to run locally.

Then add a library

In the pane, type a repo:

Agrifoodskills/Clinical-Educator-

Browse the course tree or search the speaker notes, tick the slides you want, and insert them into the open deck. They arrive bound to your template's placeholders and fully editable.

Author a library

A library repo holds a course.yaml recipe and a blocks/ directory — one folder per block, containing its deck, its lesson plans and workbooks, and its media. See the library format and the authoring grammar.
